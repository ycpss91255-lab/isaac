isaac 架構總覽

isaac 提供 Isaac Sim 執行環境與共用 Python 框架。下游專案提供場景、已轉換的 USD 模型與控制程式，即可在同一套環境播放模擬、取得感測資料與執行測試。

1. 模組邊界與依賴方向

下游可以用 Git submodule 引入 isaac。framework/isaac_devkit/ 封裝可重用的場景、感測器與 driver 邏輯；src/ 放可執行腳本、設定檔與相容入口。例如舊腳本仍可匯入 scene_builder，它從 isaac_devkit.scene 重新匯出函式。

scene 組合環境與模型，usd_model 處理 USD 結構摘要與關節 drive。感測器由 sensor_prim 載入、驗證設定並提供 prim 工具，sensors.setup_sensor() 則依 camera、LiDAR、IMU 類型建立 prim。容器啟動與 viewer 的生命週期由頂層 script/ 管理。

2. Python 對外介面與 I/O 外掛

ADR-0023 將 Python 定為框架唯一的對外程式介面。ISAAC_OUTPUT_MODE 的預設值與唯一合法值都是 python。應用以 setup_output() 建立輸出，註冊 callback，並在每次 app.update() 後呼叫 Output.step(stamp)。

ROS 2 是可替換的下游使用者。需要 ROS I/O 時，由外部 isaac_ros_io 提供實作，使用者以 ISAAC_IO_PLUGIN=module:function 指定進入點。Driver 在播放前呼叫 plugin(stage, robot_prim, config)；未設定時直接繼續。早期 ADR 中的 isaac_ros2 與 ros_io 是歷史設計，目前框架只依賴這個 Python 呼叫契約。

3. 從 CAD 資產到 USD 場景

模型匯入的交付格式是 USD。SolidWorks 匯出 URDF 後，由 asset_converter 轉換。模型的質量、碰撞與物理材質在 sim_asset 端設定，再由轉換器寫入 USD。ADR-0020 說明轉換保真度，例如有凹槽的零件可用多個 box 表示碰撞形狀，以保留實際間隙。早期 model_import 的 URDF 匯入職責已依 ADR-0026 移到轉換器，isaac 也已移除 Isaac Lab 依賴。

load_scene() 讀取一份 YAML，檢查機器人與物件的模型、姿態和覆寫欄位。相對模型路徑依序在 MODEL_PATH 搜尋，未設定時使用 <repo_root>/model/usd/。轉接器將角度制 RPY 換成 (w, x, y, z) 四元數，並依 count 與 spacing 展開物件實例。

執行時使用 Isaac Sim Core Experimental 的 USD backend，依序建立選用的 /World/ground、光源 /World/light、機器人 /World/Robot 及 /World/Objects/ 下的實例。模型以 add_reference_to_stage() 引用；spawn_overrides 可指定 visible、labels、taxonomy 等允許欄位。模型就位後，build_scene() 才逐一讀取感測器 YAML 並呼叫 setup_sensor()。

4. 播放 USD 與 driver 生命週期

已有完整場景 USD 時，可在執行中的 headless 容器使用 just run scene <usd>。這個入口以 DefaultSceneDriver 直接開啟 USD。加上 --driver <file.py> 可載入自訂的 IsaacDriver 子類別，例如在 setup(stage) 中呼叫上一節的場景組裝函式。

5. PhysX 的 L2、L3 與接觸規則

本庫的 ADR-0008 指向已移出的決策，ADR-0017 保留兩個物理層級的定義。選擇層級時，先判斷物體的位置是由 driver 指定，還是由物理求解器依受力與關節約束算出。

L2 使用 kinematicEnabled=true，以 set_kinematic_target 驅動，讓接觸積分器處理碰撞。Articulation 的 link 須維持動態。場景 YAML 的 mobility 控制物件的 schema。指定 static 時套用碰撞 schema，指定 dynamic 時再套用剛體 schema。關節及其約束來自模型 USD。

6. Docker stage 與執行用途

Dockerfile 以 NVIDIA 官方 nvcr.io/nvidia/isaac-sim:6.2.0.1 為基礎，經 sys → devel-base → devel 建立共用層。ADR-0014 依是否需要 WebRTC viewer 區分 stream 和 headless。目前 Dockerfile 另外提供桌面 gui、測試工具和串流來源映像。

headless 與 stream 啟動後都會等待使用者執行 driver。前者設定 ISAAC_LIVESTREAM=0，後者設定 2。串流冒煙腳本與 producer 均選用 NVIDIA 的 isaacsim.exp.full.streaming.kit。以 just docker run -t stream -d 啟動時，post-run hook 預設也會啟動 web-viewer；之後可在同一個容器啟動 Kit，讓瀏覽器連線觀察。

7. CI 的五個測試群組與合併條件

changes 依 PR 修改的路徑選出 core、gui、stream、headless、docs。共用層變更會選取全部群組，單改文件時只選 docs。推送至 main、發行 tag 與 merge queue 均執行全部群組。pytest 模組以 pytestmark、Bats spec 以 file_tags 宣告所屬群組；每個測試只屬於一組。

Hosted 的 docs-unit 每次執行；core-unit 與 stream-unit 依範圍執行。core-build 建置選定的 stage 並執行對應 Bats。gui 目前只有建置範圍，尚無專屬 runtime 測試。

來自同一儲存庫的 PR 可依範圍觸發 GPU 工作。core-gpu 驗證模擬整合與官方測試，core-official-nativepython 驗證 standalone Python；兩者都先等 core-unit。stream-smoke 與 stream-visual-e2e 在 stream-unit 後檢查連線與畫面；headless-smoke 確認容器能持續執行。

ADR-0010 §1 開發套件 早期四層開發環境的原文已移出。ADR-0017 將通用功能整理為下游可匯入的框架。

ADR-0012 §7 Runner 歸屬 記錄組織層級的雙 runner 拓撲與存取邊界。儲存庫整併後的配置見 ADR-0011 與 ADR-0017 的修訂。
ADR-0013 §7 測試配置 整併後 pytest 保留 unit、integration 分層；Bats 冒煙測試的位置後由 ADR-0022 調整。
ADR-0014 §6 執行與測試 stream 提供 WebRTC 觀察，headless 用於批次執行，devel-test 裝入 CI 所需工具。
ADR-0015 §2 ROS 2 下游 跨子網 Fast DDS TCP 的設定與 RGB-D 檢視操作已交由 isaac_ros_io 維護。
ADR-0016 §6 容器 hooks 沿用 base 的 run/stop hooks 管理主機設定與 viewer。當時的同庫多實例機制後由 ADR-0019 移除。
ADR-0017 §1 框架契約 確立共用框架、場景與感測器設定及 host 可匯入的約束。對外 I/O 與模型匯入邊界分別由 ADR-0023、ADR-0026 更新。
ADR-0018 §3 生成後端（已取代） ADR-0026 取代 Isaac Lab sim_utils 與 AppLauncher。現行後端以 Core Experimental 建立場景，以 SimulationApp 啟動 Kit。
ADR-0019 §6 實例範圍 移除單一 checkout 內的多實例啟動選項，預設串流流程啟動一套模擬與對應的 viewer。
ADR-0020 §3 資產保真度 記錄 URDF 轉換時的網格、碰撞幾何與關節參數處理原則；轉換工作現由 asset_converter 負責。
ADR-0022 §7 Bats 目錄 Bats 冒煙測試集中到 test/bats/smoke/，與 base 的建置與發行流程共用目錄慣例。
ADR-0023 §2 對外契約 Python 是唯一對外程式介面；ROS 2 等下游可替換，框架可獨立於中介軟體使用。
ADR-0024 §1 感測器分工 將設定與 prim 工具、建立感測器的分派邏輯及 ROS 發布拆開。現行框架保留前兩者，ROS I/O 交由下游。
ADR-0025 §2 輸出模式（已取代） 原訂的 ros／python 雙模式已撤回。現行輸出只接受 python，ROS I/O 透過 ISAAC_IO_PLUGIN 接入。
ADR-0026 §3 USD 輸入邊界 isaac 維持官方 Isaac Sim 基底，移除 Isaac Lab 依賴，只接收 asset_converter 轉好的 USD。
