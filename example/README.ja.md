# サンプル

[ROS 2 パッケージ](ros2/README.ja.md) はカメラ画像を購読し、`/cmd_vel` に速度指令を配信します。

このリポジトリにはシミュレーションのサンプルを同梱していません。[Isaac Sim 公式サンプル](https://docs.isaacsim.omniverse.nvidia.com/6.2.0/introduction/examples.html#standalone-examples)を参照してください。
